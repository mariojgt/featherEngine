# Natural landscape surfaces

These are freely available public-domain scans from [Poly Haven](https://polyhaven.com), bundled under [CC0](https://polyhaven.com/license). They may be used, modified, and redistributed commercially. Feather does not claim authorship of the source photography.

- Living ground: [Forest Leaves 02](https://polyhaven.com/a/forest_leaves_02), Rob Tuytel — moss, twigs, and leaf litter.
- Exposed soil: [Mud Forest](https://polyhaven.com/a/mud_forest), eye-candy.xyz.
- Rock: [Rock Boulder Dry](https://polyhaven.com/a/rock_boulder_dry), Dimitrios Savva and Rico Cilliers.

`provenance.json` records exact source URLs/checksums and conversions. Albedo is sRGB; OpenGL normals are linear. The app serves these files locally and embeds their bytes into authored projects; no Poly Haven API calls occur at runtime.
